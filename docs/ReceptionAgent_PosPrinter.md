# ReceptionAgent POSプリンタ

## 設定と操作

1. WindowsにUSBプリンタを登録し、テスト印刷・カットを確認する（例: `POS-80C`）。
2. ReceptionAgentの「設定」→「POSプリンタ設定」で出力を有効にし、プリンタ、医院名、80mm／58mmを選ぶ。初期値は出力OFF、`POS-80C`、80mm。
3. 患者用とスタッフ用のタブで各行の文面・フォント・サイズ・太字・後の余白・配置・枠囲いを編集する。「見本・テスト印刷」でプレビューやサンプル印刷ができる。「適用」後、親の設定画面で「保存」する。
4. 一覧の患者を選び「POS発券（2枚）」でプレビューを開き、印刷する。患者用→スタッフ用の順に各1ページを送信する。再操作は再印刷になる。

発券対象はカルテ番号・予約番号を取得でき、競合や本人照合不一致がない受付。職員確認中やKiosk自動処理中は発券ボタンを無効にする。日付時刻にはXML取得日時（Kioskでは受付開始日時）を使用する。

既定のWindowsプリンタは使用せず、設定したプリンタ名を使用する。手動印刷ダイアログでは別のプリンタへ変更できる。Kiosk自動発券は自動受付設定のプリンタ名を使う。

Kiosk自動発券は、別途「Kiosk自動受付設定」で自動発券をONにしてプリンタを指定する。POS出力ONだけでは自動発券されない。用紙幅・医院名・文面は共通設定を使う。既存の対象判定、二重発券防止、結果不明時に自動再発券しない動作を維持する。

## 文面

差し込み項目: `{医院名}`、`{日付時刻}`、`{予約番号}`、`{番号}`、`{名前}`、`{フリガナ}`、`{マイナ氏名}`、`{マイナフリガナ}`、`{診察券番号}`。`{番号}`と`{予約番号}`は同じ予約番号。診察券番号にはカルテ番号を使用し、先頭のゼロを保持する。各行の固定文字も自由に編集できる。

`{名前}`と`{フリガナ}`はマイナXMLの漢字氏名・氏名カナを優先する。XML側の値がない場合は従来の氏名情報に補完する（手動発券の氏名はカルテ→iCall予約、Kioskは確認済み氏名。フリガナはカルテ）。`{マイナ氏名}`と`{マイナフリガナ}`はXML由来の値だけを出力し、取得できなければ印刷を止めて通知する。他の取得元へ黙って置き換えない。

各行にフォント（利用PCにインストールされたフォント）、サイズ6～48pt、太字、行の後の余白0～20mm、左寄せ／中央寄せ／右寄せを指定できる。配置の初期値は中央寄せ。余白はその項目と次の項目の間の追加余白で、長い氏名が折り返された項目内の行間はフォントの標準行間を使用する。空行、最下行での行追加、行選択＋Deleteでの削除、「行を上へ／下へ」の並べ替えに対応する。既存設定に書式がなければ従来のフォント・サイズ・余白で読み込む。

「スタッフ用のフォント・文字サイズを患者用に合わせる」は初期値ON。同じ項目（名前・フリガナ・日付時刻・番号・診察券番号など）の患者用フォントとサイズを使う。患者用に対応行がない通常の行は、患者用の最初の通常行に合わせる。スタッフ用の配置・太字・余白・枠囲いは個別設定を維持する。OFFにするとスタッフ用のフォント・サイズを個別に編集できる。

スタッフ用の「スタッフにお渡し下さい」は初期状態で枠囲いする。文面欄を「受付スタッフへお渡しください」などに変更しても、枠囲いをONにしていれば枠を維持する。各行の「枠囲い」で他の項目も囲める。用紙長の計算には枠内の余白を含め、58mm・80mmともに折り返しに対応する。

新規設定の患者用の初期文面は医院名、日付時刻、予約番号、名前、フリガナ、診察券番号。スタッフ用は「スタッフにお渡し下さい」、番号、日付時刻、名前、フリガナ、診察券番号。長い氏名は用紙幅に合わせて折り返す。保存済みの文面には自動で行を追加せず、フリガナを出すには任意の行に`{フリガナ}`または`{マイナフリガナ}`を追加する。

## 用紙とカット

Windowsドライバで印刷する。用紙幅はアプリとドライバの両方で合わせ、プリンタドライバの**ページごとの自動カット**を有効にする。文面に応じた用紙長で2ページを送信する。ドライバが任意用紙サイズを受け付けない場合や印刷領域に収まらない場合はエラーになる。

USB機器の実印刷とカットは利用PCで確認する必要がある。キューへの送信成功は物理的な印刷完了を意味しない。途中失敗時には一方の用紙だけ出ている可能性があるため、キューと用紙を確認してから手動で再操作する。

## その他の変更

- 「アプリ起動時に監視を開始する」を追加。初期値OFF。ON時は通常の監視開始と同じ設定検証を実行する。
- 設定画面のフォルダー入力はフォーム幅に合わせ、右端の「参照」を確保する。
- 一覧はファイル名とそれ以降の日時・再検証列を非表示にする。これらは行のダブルクリックで確認できる。
